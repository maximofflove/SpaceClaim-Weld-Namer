# Руководство пользователя — SpaceClaim Named Selection Namer v0.15.8

Ниже описаны все основные элементы интерфейса и логика тестовой версии v0.15.8.

## 1. Главное окно

### Group purpose
Выбирает workflow и правила имён. Режимы независимы: нумерация `w`, `f`, `fm` и `ctkt` не влияет друг на друга.

### Selection type
Определяет допустимую геометрию. Weld допускает Faces или Edges. Bolt зафиксирован на Edges. Face Meshing и Contact — только Faces.

### Create Next
Читает существующие группы root part, определяет первое свободное имя, проверяет текущее выделение и создаёт одну Named Selection со всеми выбранными допустимыми объектами. Существующее целевое имя не перезаписывается. До изменения модели выполняются mode-specific проверки, включая запрет перекрытия `fm` и Bolt screening.

### Check Next Name
Read-only операция. Показывает следующее имя, текущую пару/группу и количество просмотренных групп. Удобно после ручного редактирования дерева.

### Auto highlight after Create
После успешного Create Next автоматически подсвечивает созданную пару/группу. На модель не влияет.

### Show names of highlighted Named Selections
Добавляет временные подписи рядом с подсвеченной геометрией. Это graphics overlay, а не CAD-объекты и не annotations модели.

### Label size (%)
Масштабирует временные подписи в диапазоне 10–500%. Подписи находятся в model space, поэтому визуальный размер также зависит от zoom камеры.

### Bolt axis tolerance (degrees)
Активно в Bolt mode. Максимальное угловое отклонение при проверке оси Bolt pair. По умолчанию 1°. Это геометрический screening, а не критерий прочности болта.

### Highlight Current Pair / Current Group
Подсвечивает текущую логическую пару, определённую по последовательности имён. Для pair mode используются A/B, если обе стороны существуют. В `fm` подсвечивается одна группа.

### Highlight All ...
Подсвечивает все группы активного назначения. Weld/Bolt: A синяя, B красная. Face Meshing: синяя. Contact: A приглушённо-синяя, B песочная.

### Clear Highlight
Убирает обычную подсветку, временные подписи и оранжевые QA overlay. Named Selections и CAD не изменяются.

### Weld Named Selection QA / Repair Manager
Открывает таблицу QA и ремонт Weld pair.

### Contact Named Selection QA / Repair Manager
Доступно в Contact mode начиная с v0.15.8. Логика аналогична Weld, но все Contact-группы и repair selection должны быть Faces.

### Check Existing Bolt Pairs
Read-only audit. Выдаёт OK / ERROR / INCOMPLETE, проверяет геометрию круговой кромки/опорной плоскости и отклонение оси пары, если обе стороны существуют. Named Selections не редактируются.

### Check Existing Face Meshing
Read-only audit всех `fm`-групп. Ищет Faces, одновременно входящие в несколько групп, и подсвечивает пересечения синим. Если группу нельзя прочитать, это сообщается как неполная проверка.

### Find Groups for Selected Geometry
По текущему выделению SpaceClaim показывает все группы активного режима, содержащие эти объекты. Особенно полезно в большой модели или при намеренно общей геометрии.

### Output panel
Показывает последнее действие, количество объектов, предупреждения, результат проверки или traceback ошибки. Если визуально кажется, что кнопка ничего не сделала, сначала смотреть сюда.

## 2. Weld / Contact QA and Repair Manager

### Validate All
Заново читает все pair-группы из модели и полностью перестраивает таблицу QA.

### Show Problems Only
Фильтрует таблицу до ERROR/CHECK. Результаты валидации не меняются.

### Highlight Problems
Оранжевым overlay подсвечивает геометрию проблемных пар.

### Clear Problem Highlight
Убирает только оранжевую QA-подсветку.

### Export CSV
Сохраняет текущие записи QA в CSV. Weld и Contact имеют отдельные имена файла по умолчанию. Экспортируются имя пары, A/B, типы, количества, metric difference, status и reason.

### Колонки таблицы
- **Weld / Contact** — логическая пара;
- **A / B** — фактические имена групп;
- **Type A / Type B** — определённый тип геометрии;
- **Count A / Count B** — количество объектов;
- **Metric diff %** — относительное отличие суммарной длины Edges или площади Faces;
- **Status** — OK, CHECK или ERROR;
- **Reason** — причина; разница количества объектов может быть только информацией.

### Previous Problem / Next Problem
Быстро перемещает выделение таблицы между проблемными строками.

### Highlight Selected Pair
Подсвечивает выбранную строку нормальными цветами A/B.

### Zoom Selected Pair
Временно использует геометрию пары для SpaceClaim zoom-to-selection, затем возвращает пользовательскую подсветку A/B.

## 3. Кнопки Repair

Repair всегда использует **текущее primary selection SpaceClaim**. Строка таблицы определяет, какая Named Selection будет изменена.

### Replace A / Replace B
Полностью заменяет содержимое выбранной стороны на текущее выделение SpaceClaim.

### Add to A / Add to B
Добавляет текущее выделение к существующей стороне, удаляет дубли, обновляет Named Selection через поддерживаемую V19-команду, повторно читает результат и валидирует пару.

### Remove from A / Remove from B
Удаляет только те выбранные объекты, которые реально входят в сторону. Если совпадений нет — ничего не меняется. Если удаление оставит группу пустой — операция блокируется; для полной замены следует использовать Replace.

### Create Missing A / Create Missing B
Создаёт отсутствующую сторону из текущего выделения. Если сторона уже существует, операция отменяется.

### Highlight Conflict
Оранжевым показывает точную геометрию конфликта: один объект в A и B либо использование объекта другими pair-группами. Если конфликта нет, показывается обычная пара.

### Подтверждение и постпроверка
Каждая операция, меняющая модель, показывает подтверждение. Существующая группа меняется через `NamedSelection.Replace(...)`; `Group.Members` считается read-only. После изменения группа заново разрешается из модели, проверяется геометрия, таблица строится повторно и изменённая пара снова выбирается.

## 4. Как понимать статусы QA

**ERROR** — структурная проблема группы: отсутствующая сторона, пустая/неразрешённая группа, недопустимая или смешанная геометрия, несовпадение типов A/B, один объект одновременно в A и B, дубли имени без учёта регистра, проблемы последовательности.

**CHECK** — screening warning. Например, отличие суммарной длины/площади больше 10% или использование геометрии другой pair-группой.

**OK** означает только отсутствие реализованного QA finding. Это не доказательство корректности инженерной модели.

Разное количество объектов A/B считается информацией: одна физическая поверхность может быть по-разному разбита топологически.

## 5. Правила Contact pair

- имена `ctktNa` / `ctktNb`;
- создание и Repair — только Faces;
- A = приглушённо-синяя, B = песочная;
- для metric screening используется суммарная площадь Faces;
- повтор одного Face внутри A/B и использование другими Contact-группами фиксируется QA;
- инструмент управляет Named Selections, но не создаёт Contact Region в Mechanical и не назначает Contact/Target properties.

## 6. Рекомендуемая последовательность Repair

1. Открыть QA / Repair Manager и нажать **Validate All**.
2. Выбрать нужную строку.
3. Нажать **Highlight Selected Pair** или **Zoom Selected Pair** и визуально убедиться, что выбрана правильная пара.
4. Выделить в SpaceClaim точную геометрию для Add/Remove/Replace.
5. Нажать нужную Repair-кнопку.
6. Проверить old/selection/result counts в confirmation dialog.
7. После операции проверить автоматически обновлённый статус и подсветку.
8. При необходимости сохранить CSV как запись проверки.
